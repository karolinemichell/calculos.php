# calculos.php
Ejercicios de Calculo de sueldo Quincenal y de Facturacion

Este repositorio contiene dos ejercicios desarrollados en PHP y HTML para el procesamiento de datos desde el servidor:

1. **Calculadora de Sueldo Quincenal (index.php)**: Permite ingresar los datos de un empleado y sus horas trabajadas (diurnas, vespertinas y nocturnas) para calcular el sueldo bruto, aplicar retenciones proporcionales (Ahorro Habitacional y Seguro Social) y generar el recibo con el sueldo neto a cobrar.
2. **Sistema de Facturación (facturacion.php)**: Recibe la descripción de un artículo, la cantidad adquirida y su precio unitario. Aplica un 12% de IVA y evalúa si el monto supera los $150 para otorgar un descuento del 15% antes de mostrar el desglose de pago final.

## Requisitos de Ejecución
- Servidor Web local (XAMPP, WAMP, Laragon) con soporte PHP.
- Colocar los archivos en la carpeta `htdocs` y acceder mediante `http://localhost/`.
